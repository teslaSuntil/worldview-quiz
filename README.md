# Тест мировоззрения

Интерактивное React-приложение для сравнительного анализа религиозных убеждений.

## Установка и запуск

1. Убедитесь, что у вас установлен Node.js (версия 14 или выше)

2. Перейдите в папку проекта:
```bash
cd D:/worldview-quiz
```

3. Установите зависимости:
```bash
npm install
```

4. Запустите приложение в режиме разработки:
```bash
npm start
```

Приложение откроется в браузере по адресу http://localhost:3000

## Сборка для продакшена

Для создания оптимизированной версии для развертывания:
```bash
npm run build
```

Готовые файлы будут находиться в папке `build/`
