Как загрузить на хостинг:

1. Откройте папку D:\worldview-quiz\build
2. Скопируйте ВСЕ файлы из неё (index.html, папка static и остальное)
3. Загрузите их на хостинг через FTP или панель управления хостингом
4. Готово! Сайт будет работать

Локально проверить:
Откройте D:\worldview-quiz\build\index.html в браузере — должен работать без установки.

Для хостинга подходят:
- Netlify (бесплатно, просто перетащить папку)
- Vercel (бесплатно для React)
- GitHub Pages (бесплатно)
- Любой хостинг с поддержкой статических файлов

Проект готов к развёртыванию!
